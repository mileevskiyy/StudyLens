# GitHub и демка StudyLens

## Как посмотреть

Открой ссылку **Live demo** в начале README и нажми **Try the demo**. Создаётся отдельное учебное пространство с четырьмя примерами коллекций.

Для короткой демонстрации:

1. Открой **Collections → New collection**.
2. Добавь заметку во вкладке **Notes**.
3. Нажми **Turn an idea into a card**, отредактируй вопрос и ответ, сохрани.
4. Нажми **Review collection**, попробуй вспомнить ответ, затем **Reveal answer**.
5. Выбери оценку: Again / Hard / Good / Easy. Посмотри **Your progress**.
6. Для сохранения материалов открой **Library & settings → Export library**.

Демка хранит данные до перезапуска сервера или 24 часов без активности. Каждый посетитель получает собственное пространство. Экспорт сохраняет карточки и заметки, без расписания и истории повторений. Импорт добавляет новые копии коллекций.

## Как проверить на GitHub

Во вкладке **Actions** открой последний запуск **Learning workflow checks**. Зелёный результат означает, что автоматические проверки, сборка и браузерный сценарий прошли для данного коммита. При ошибке открой упавший шаг; браузерный отчёт сохраняется в артефакте `browser-evidence`.

Сам GitHub показывает код и документацию. Рабочая серверная демка открывается по ссылке **Live demo**; GitHub Pages не запускает этот Node.js/SQLite сервер.

## Если загружаешь архив вручную

1. Распакуй архив StudyLens.
2. Создай пустой репозиторий `StudyLens` в своём аккаунте GitHub.
3. Загружай содержимое папки, чтобы `package.json`, `Dockerfile` и `README.md` находились в корне репозитория.
4. Обязательно включи скрытую папку `.github` с автоматическими проверками.
5. Не добавляй `node_modules`, `.env`, базы данных, `dist` или папку результатов тестов.
6. Укажи адрес опубликованной демки в разделе **About → Website**.

При работе через Git:

```sh
git init -b main
git add .
git commit -m "Build StudyLens learning workspace"
git remote add origin https://github.com/mileevskiyy/StudyLens.git
git push -u origin main
```

Если репозиторий уже настроен, используй существующий `origin` и добавляй изменения обычным коммитом.

## Локальный запуск

Установи Node.js 24, затем в папке проекта выполни:

```sh
npm ci
npm run build
npm start
```

Открой `http://127.0.0.1:3500`. Интернет нужен для установки зависимостей; сама учебная логика не обращается к сторонним API. Шрифты могут загрузиться из Google Fonts, а при недоступности используются локальные замены.

# Future work

These are potential extensions, not implemented features.

- Add authenticated accounts, recovery and explicit library ownership for durable multi-device use.
- Implement an established scheduling model behind an interface, with migration tests and published algorithm provenance.
- Add user-selected timezones and tests for daylight-saving changes.
- Add structured note formatting, attachments and accessible math rendering.
- Separate history from content storage for larger libraries and paginated analytics.
- Add import preview, duplicate detection and optional content merge.
- Add optimistic concurrency to notes and collection metadata.
- Add richer accessibility testing, offline support and optional review reminders.
- Add load testing and documented operating limits before supporting a real classroom or shared deployment.
